# Депеша — как здесь работать

Геополитическая симуляция: 32 страны, 2026–2042, ход равен месяцу.
Игрок ведёт одну страну, остальные ведёт ИИ. Чистый Python без
зависимостей, интерфейс без сборки.

---

## Первая команда каждой сессии

```
python3 tools/status.py
```

Печатает последние решения, открытые пункты очереди и результат
проверок. **Не начинай писать код, не прочитав `docs/DECISIONS.md` по
теме пункта.** Один раз это уже стоило затёртых файлов данных: сессия
началась с попытки реализовать то, что уже было сделано и лежало в
репозитории.

Последняя команда перед коммитом:

```
python3 tools/check.py
```

Семь проверок: демонстрационный прогон, отсутствие мёртвых ходов,
заметность механик, живость макропоказателей, ревизия, разбор скриптов
интерфейса, работа страницы в эмуляторе браузера.

---

## Где что лежит

```
engine/     движок: состояние мира, каналы влияния, сделки, повестка,
            группы, правительство, эскалация, экономика, кадры
api/        сервер без зависимостей: только стандартная библиотека
web/        интерфейс: три файла плюс материалы (флаги, иконки, звук)
data/       все числа и весь текст игры — в CSV, не в коде
docs/       DECISIONS.md — журнал решений, главный документ проекта
tools/      проверки и генераторы
```

## Правила, которые нельзя нарушать

**Числа живут в `data/`, не в коде.** Любую величину, которую захочется
подкрутить, кладут в таблицу.

**Ядро детерминировано.** Один и тот же сид даёт одну и ту же партию.
Случайность берётся только из переданного генератора.

**Игрок не видит сырых чисел.** Всё, что уходит наружу, проходит через
`engine/legible.py` и превращается в полосу и слово. Число показывается
только там, где им управляет сам игрок, — положение ползунка.
Проверяется `tools/legibility.py`.

**У игрока всегда есть ход.** Ограничение звучит как «всё, что можешь,
стоит того, чего жалко», а не «ты не можешь ничего». Проверяется
`tools/deadend.py`.

**Механика, которую не видно, — не механика.** Если эффект не двигает
полосу хотя бы на половину деления за три года, его либо усиливают,
либо убирают. Каждая новая механика добавляется в `tools/legibility.py`.

**Два языка.** Всё, что видит игрок, проходит через `engine/i18n.py`
или пару столбцов `name_ru` / `name_en`. Комментарии и ключи остаются
по-русски и не переводятся. Полнота проверяется ревизией.

**Решение записывается в `docs/DECISIONS.md`.** Что решили, почему, что
отбросили и что нашла проверка. Журнал — главный артефакт проекта:
кода без него не понять.

## Чего стоит остерегаться

Эти ошибки уже случались, каждая по нескольку раз.

**Запятая внутри значения CSV без кавычек.** Разносит строку на лишние
поля; код, читающий по именам столбцов, молча это терпит, а значение
обрезается на первой запятой. Так пострадали пять таблиц. Писать только
через `csv.writer`, проверять ревизией.

**Запись в файл до того, как данные собраны.** `open(path, "w")`
обрезает файл сразу, и падение на середине оставляет половину. Писать во
временный файл и подменять через `os.replace`.

**Удаление функции по границам блока.** Трижды задевало соседнее:
пропадали константы и целые функции. Удалять точечной подстановкой, а
после каждой вычистки прогонять `tools/check.py`.

**Проверка, которая меряет одну точку.** Один контрольный замер по
одной паре стран объявил фон вчетверо сильнее, чем он есть, и вызвал
ненужную тревогу. Мерить по распределению.

**Окно замера, отставшее от такта.** После перехода с кварталов на
месяцы константа осталась прежней, и три года превратились в один.
Проверка молча ужесточилась втрое.

## Тон

Игра соглашается с целью игрока и показывает цену, а не поучает.
Формулировка «не получилось» не используется: называется ограничение,
которое сработало. Подробнее — `docs/UI.md` и `docs/GENRE.md`.
