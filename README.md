# Депеша

Геополитическая симуляция: 32 страны, 2026–2042, ход равен месяцу. Вы
ведёте одну страну, остальные ведёт ИИ.

В основе — двухуровневая игра. Чтобы договориться с кем-то снаружи,
нужно одновременно устроить и партнёра, и собственную коалицию дома.
Если между тем, что готов принять он, и тем, что пропустят у вас, нет
просвета — сделки нет, и игра прямо называет, кто именно её похоронил.

## Запуск

Нужен только Python 3.11 или новее. Зависимостей нет.

```
python3 api/server.py          # открыть http://localhost:8000
```

или `./run.sh`, или `make run`.

## Что уже работает

- **Переговоры** с двумя порогами: потолок ратификации дома и порог
  принятия у партнёра. Чужой порог виден неточно — его оценивает
  разведка, и ошибка в оценке срывает сделку.
- **Пакетные сделки**: неделимый вопрос решается доплатой по делимому.
- **Внутренняя политика**: десять групп интересов, пятнадцать
  министерств, тридцать четыре рычага, выборы, конфликты в кабинете.
- **Кадры**: министры и послы с пригодностью к посту; компетентный
  исполнитель сужает разброс между замыслом и результатом.
- **Эскалация**: лестница от напряжения к развязке, где контроль над
  территорией может сменить хозяина.
- **Экономика**: ВВП, курс валюты, экспорт и импорт по партнёрам,
  структура вывоза по отраслям.
- **Повестка**: игра сама приносит вопросы, порождённые состоянием
  мира, а не сценарием. Бывают и спокойные месяцы.
- Русский и английский язык, звук, меняющийся от обстановки.

## Команды

```
python3 tools/status.py       где проект стоит — первая команда сессии
python3 tools/check.py        все проверки: движок и интерфейс
python3 tools/check.py --fast быстро, без долгих прогонов

python3 tools/deadend.py      нет ли ходов без вариантов
python3 tools/legibility.py   заметны ли механики игроку
python3 tools/macro.py        живут ли макропоказатели за партию
python3 tools/drift.py        из чего складывается дрейф мира
python3 tools/audit.py        ревизия: что написано, но не подключено

python3 tools/sound.py        пересобрать звуки и музыкальные слои
python3 tools/portraits.py    пересобрать пул портретов
python3 tools/clips.py        пересобрать заглушки роликов
python3 tools/ingest.py DIR   загрузить данные из выгрузок
```

Проверка страницы в эмуляторе браузера требует `npm install jsdom`;
без него остальные шесть проверок работают как обычно.

## Устройство

```
engine/     движок: мир, каналы влияния, сделки, повестка, группы,
            правительство, эскалация, экономика, кадры, два языка
api/        сервер на стандартной библиотеке
web/        интерфейс без сборки: три файла и материалы
data/       все числа и весь текст игры
docs/       журнал решений и спецификации
tools/      проверки и генераторы
```

## Принципы

Числа живут в таблицах, не в коде. Ядро детерминировано: один сид —
одна партия. Игрок не видит сырых чисел, только полосы и слова. У игрока
всегда есть ход. Механика, которую не видно, — не механика. Каждое
решение записано в журнал.
