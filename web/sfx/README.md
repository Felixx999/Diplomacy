# Звуки интерфейса

Пока звучит синтез: одиннадцать откликов рождаются на месте через Web
Audio, без файлов. Это позволило отладить связь звука с действиями сразу.

Чтобы заменить на записи, положите сюда файлы с этими именами и
подключите их в `audio.js` вызовом `Audio_.load('имя', '/sfx/файл.ogg')`.

| Имя | Когда звучит | Каким должен быть |
|---|---|---|
| `click` | нажатие обычной кнопки | сухой щелчок, не длиннее 0.1 с |
| `tab` | переход между разделами | мягче щелчка, чуть выше |
| `slider` | отпускание ползунка | едва слышный, чтобы не мешал при перетаскивании |
| `good` | действие удалось | короткий восходящий, без литавр |
| `bad` | действие отклонено | нисходящий, глухой, без резкости |
| `notify` | всплывающее сообщение | негромкий сигнал внимания |
| `alert` | кризис по обстановке | низкий, тревожный, единственный «громкий» |
| `sign` | подписание соглашения | чернильный росчерк, тяжёлая печать |
| `turn` | смена месяца | глубокий удар, задаёт ритм партии |
| `open` / `close` | открытие и закрытие окна | пара, вторая ниже первой |

**Откуда брать.** Подойдут наборы под CC0 или общественным достоянием —
freesound с фильтром по лицензии, а также сгенерированные. Требования:
моно или стерео, 44.1 кГц, ogg или mp3, каждый файл не длиннее секунды,
нормализованы по громкости между собой.

**Чего избегать.** Звуков из других игр и фильмов: узнаваемость обернётся
претензией. Длинных хвостов — при быстрой игре они наложатся друг на
друга. Ярких «победных» аккордов на обычных действиях: в игре про
дипломатию каждый второй клик не победа.
