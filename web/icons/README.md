# Иконки

Набор из [Tabler Icons](https://github.com/tabler/tabler-icons) под
лицензией MIT (Paweł Kuna), файл `LICENSE` рядом. Отобрана шестьдесят
одна иконка в одном весе линии.

Соответствие сущностям игры задаётся в `data/icons.csv`: министерства,
направления внешней политики, типы вопросов, группы интересов, шкалы.

## Чего здесь нет и почему

**Государственных гербов.** В отличие от флагов, гербы во многих
странах ограничены отдельными законами об использовании официальных
символов, а не авторским правом. Свободная лицензия на изображение от
этого не защищает.

**Эмблем международных организаций** — НАТО, ООН, ЕС, ОПЕК. Это
охраняемые знаки; эмблема ООН вдобавок защищена отдельной резолюцией и
национальным законодательством ряда стран.

Вместо них — оригинальные знаки блоков, собираемые из геометрических
форм в `engine/portrait.py`: форма по типу обязательств, гамма по
региону покровителя. Узнаются по форме, ничего не копируют.
