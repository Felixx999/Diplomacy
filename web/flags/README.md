# Флаги

Набор взят из [flag-icons](https://github.com/lipis/flag-icons) под
лицензией MIT (Panayiotis Lipiridis), файл `LICENSE` рядом.

Государственные флаги сами по себе не являются объектом авторского
права: это официальные символы. Лицензия относится к конкретной
векторной отрисовке из набора.

Тридцать два файла по кодам стран проекта, соотношение 4:3.

**О спорных образованиях.** Тайвань, Косово, Палестина и Западная Сахара
представлены наравне с остальными. Наличие флага не означает позиции
проекта по их статусу: признание у нас — отдельная переменная (решение
Р-07), и интерфейс называет долю признающих государств рядом с флагом.
